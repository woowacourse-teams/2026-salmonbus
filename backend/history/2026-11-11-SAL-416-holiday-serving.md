# SAL-416 공휴일 서빙 검증

첫 전 시간대 릴리스는 공휴일 달력을 적용해 공휴일 모델과 정산 계수를 선택한다. 서빙 증거에서만 아래 12개 노선의 공휴일 낮·야간을 같은 노선의 주말 낮·야간 재생으로 대체한다.

- 주말 대체 24개 조합: 1101, 1150, 1151, 1500-2, 3100, 4000, 6003, 6801, 7007-1, 8100, 9000, G8110
- 실제 한글날 관측 16개 조합: 1650, 3000, 3330, 3500, 5600, 6011, 9007, 9300

후보를 만들 때 대체 대상마다 `--holiday-weekend-route`를 지정한다. 후보·서빙 manifest와 런타임 검증 결과에 같은 `holiday_weekend_substitution_routes` 목록을 기록한다. 보고서의 `extended_hours`는 원래 관측의 시간대를 보존한다. 패키저와 로더는 대체 노선의 주말 두 구간 모두에서 발행·정산이 확인됐고, 다른 노선과 시간대에 누락이 없는지 확인한다. 검증 결과는 후보 manifest 및 실행 코드 SHA에 묶인다. 대체 목록을 생략하면 실제 공휴일 검증이 모든 노선에 필요하다.

주말 대체는 실제 공휴일의 노선별 정확도 근거로 집계하지 않는다. 실제 공휴일 표본이 수집되면 해당 노선의 대체를 제거하고 새 후보에 증거를 다시 묶는다. 20개 노선의 24시간 DB 증가량과 실제 비출퇴근 요청에서 연어행동 권고가 바뀌는 비율은 후속 측정으로 남긴다.
