# 전체 MAE 기준 레스와 동키 결합 모델

사용자가 전체 좌석 오차 최소화를 선택했다. 기존 좌석 88열과 학습 표본, 하차 후 추정 좌석 목표를 유지하고, 레스 회귀와 동키의 3단계 분류 구조를 하나의 예보 파이프라인으로 결합했다. 원본 재현 모델은 덮어쓰지 않았다.

## 선택한 모델

좌석 회귀는 기존 제곱오차 회귀와 새 절대오차 회귀의 예측을 50:50으로 합친 것이다. 새 회귀는 추정 정답을 반올림하지 않고 학습했다. 두 회귀의 초기값과 잎 값을 가중해 단일 가산 트리로 저장했다. 기존 분류기는 0석 / 1~2석 / 3석 이상을 분류한다.

최종 좌석 = `clip(p(1~2석) × 1.3453361814667888 + p(3석 이상) × max(0, 회귀값), 0, 70)`.

별도 출발 만석 확률 모델과 80열 입력은 보존했다. 분류기의 0석 확률을 개인의 탑승 확률로 바꾸지 않았다. Java 추론 구조와 입력 계약이 같아 Java 알고리즘 수정 없이 별도 번들로 내보냈다.

## 실제 개발 평가

학습은 10월 12일 이전 714,169행으로 제한했다. 후보 선택 기간 10월 12~16일은 810,722행, 후속 확인 기간 19~21일은 339,782행이다. 모든 MAE는 예보 행마다 동일한 비중으로 계산했다.

| 후보 | 12~16일 MAE | 19~21일 MAE | 전체 MAE |
|---|---:|---:|---:|
| 기존 결합 | 2.232476 | 2.292942 | 2.250333 |
| 절대오차 회귀 200단계 + 분류 | 2.333394 | 2.405733 | 2.354758 |
| 절대오차 회귀 400단계 + 분류 | 2.250966 | 2.318619 | 2.270946 |
| 새 회귀 비중 25% + 분류 | 2.213751 | 2.275872 | 2.232098 |
| 새 회귀 비중 50% + 분류 | **2.210096** | **2.273775** | **2.228903** |
| 새 회귀 비중 75% + 분류 | 2.222194 | 2.287792 | 2.241567 |

새 회귀 단독 교체가 실패한 뒤 혼합 후보를 추가 비교했다. 두 기간은 이전 연구에서도 사용했으며 이번에도 반복 확인한 개발 자료다. 독립적인 최종 평가가 아니다. 전체 MAE는 기존 결합보다 0.021430석, 0.9523% 감소했다. 레스 회귀 단독의 기존 평가 2.272514석과 비교하면 약 1.92% 감소다.

전체 평균은 개선됐지만 3000번 노선은 1.38% 악화됐다. 다른 7개 노선은 개선됐다. 전체 MAE를 우선하는 사용자 선택에 따라 채택했다. 정답 0~2석 중 3석 이상 많게 예보하는 비율은 23.9983%에서 23.8700%, 전체 예보 중 3석 이상 적게 예보하는 비율은 12.5007%에서 11.9364%로 변했다.

## 검증과 파일

- 혼합 트리와 직접 가중 예측을 전체 평가 행에서 허용 오차 1e-9로 대조했다.
- 선택 모델을 joblib으로 저장하고 다시 읽어 전체 평가 예측이 정확히 같은지 확인했다.
- 실제 입력 1,023개와 합성 경계 481개에서 Python/Java 대조가 통과했다. 최대 좌석 차이는 8.88e-16석이다. 이것은 연구 입력 기준 추론 대조이며 실시간 입력 검증이 아니다.
- Python 도구 검사 21개가 통과했다. Java 알고리즘은 변경하지 않았다. 전체 CI는 사용자 요청에 따라 재실행하지 않았다.
- 학습은 nice 10과 단일 스레드로 실행했다. 첫 학습/평가 약 214초, 저장 모델을 재사용한 추가 비교 약 330초. 확인한 RSS는 최대 약 2.9GB였다.

도구: `backend/tools/les_model/optimize_combination.py`. 원본 비교는 `--run <reproduction> --output <새 경로>`, 혼합 추가 비교는 `--expert-reference <첫 실행 출력>`을 더해 재실행한다. 고정된 재현 가상환경과 신뢰할 수 있는 로컬 pickle 자료가 필요하다. 원본 모델 해시와 입력 해시, 파이썬 환경을 검사한다. 기존 출력 경로는 덮어쓰지 않는다.

실제 산출물은 저장소 밖 `reproduction-20261104/combined-mae-blend-20261104`에 보존했다. `comparison.json`, `expert.joblib`, `bundle`, `java-parity.json`, `combined-seat-model-20261104.zip`이 있다. ZIP은 원자료 없이 JSON 번들과 검증 결과, README를 담으며 5,163,064바이트다.

번들 manifest SHA-256: `efeca3e8f9b6d06169cffd00ded2f2c12d3e5e68e65c8bf03373008b3cedfeb6`.

## 남은 검증

`serving_ready=false`를 유지한다. 후속 관측을 미리 사용하지 않는 온라인 입력 재생, 새로운 기간 평가, 실제 Worker 처리량과 메모리 검증은 남아 있다. 회귀 트리가 400개에서 800개로 늘어 정확도 개선에 처리 비용이 따른다. 이 보고서는 운영 정확도 향상이나 운영 활성화 완료를 주장하지 않는다.
