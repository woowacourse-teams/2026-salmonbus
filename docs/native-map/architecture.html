Salmonbus · iOS native 지도 설계

앱에서는 네이버 iOS SDK로 지도만 그리고, 지금의 웹 Bottom Sheet와 정류장 목록을 그 위에 겹칩니다. 탭을 눌러 화면의 두 레이어, 터치 담당, 데이터 흐름, 준비와 복구를 차례로 살펴볼 수 있습니다.

이 페이지는 구조를 이해하기 위한 설명용 시뮬레이션입니다. 실제 네이버 지도·UIKit 제스처를 실행하지 않습니다. 영역 적용 지연은 설명을 위해 단순화했으며, 실제 구현과 검증 범위는 설계 문서와 PR 본문에서 구분합니다.
